## Per-figure notes

### `climatology_envelopes_by_region.pdf`
```
python plot_climatology.py analysis.experiment=<out_dir> analysis.experiments_to_plot=[...] analysis.experiment_names=[...]
```
Pools per-model climatology across all 11 hindcast starts (see `ALL_STARTS` in the script). `analysis.start_month` controls the calendar alignment; MESMER/DiffESM get an extra `-1` offset internally (`_reduce_to_climatology`) to correct for their 1-month calendar shift relative to ArchesClimate/target data — do not "fix" this by changing `start_month` itself.

### `rank_histogram_headline.pdf`, `temporal_psd_headline.pdf`
Produced by **`regen_psd_rankhist.py`**, run standalone (`python regen_psd_rankhist.py`, writes under `ARCHESCLIMATE_PLOTS_ROOT`). It pools over the available hindcast starts; see the metric conventions below for baseline coverage.

`plot_metrics.py` also has code that writes figures with these same names (`plot_rank_histogram`/PSD calls around line 1440), but it is **not** a substitute: its target/prediction loading (`plot_metrics.py:1319-1328,1352-1354`) reads a single hardcoded `target_path` built from one `(inference.target, inference.year)` pair, with no loop over multiple starts anywhere in that code path. It can only ever pool one hindcast start (whichever one the hydra override selects, defaulting to `test`/`0`) — it has no mechanism to reproduce the 11-start pooling in the current figures. `regen_psd_rankhist.py` is the only script currently capable of regenerating these two figures; do not delete it, and don't rely on `plot_metrics.py`'s rank-histogram/PSD output for the paper unless it's rewritten to loop over all 11 starts the way `plot_climatology.py`'s `ALL_STARTS` does.

### `headline_var_rollout_tropics.pdf` / `headline_var_rollout_tropics_anomalies.pdf`
```
python regional_analysis.py --config-name=config +analysis=regional_analysis
```
Single run produces both the raw and anomaly versions (`headline_var_rollout_tropics` and `_anomalies` outputs, see `regional_analysis.py:436,440`).

### `50_year_rollout.pdf`
```
python plot_50yr_anomaly.py
```
600-month (50-year) autoregressive rollout of the headline flow model from the real 1960 initial condition, forced vs. flat forcing, with real DCPP ensembles at the 1960 start and 2010 end plotted as reference. Writes `50_year_rollout.pdf` under `ARCHESCLIMATE_PLOTS_ROOT`. Plots anomalies from each series' own baseline rather than absolute values.

## Tables (bootstrap methodology, `sec:hindcast_bootstrap`)

Not figures, but reproduced here since they share the same bootstrap infrastructure described once in the paper and used by every results table:

- **Table 3** (deterministic ablations): `bootstrap_table3.py` (per-model bootstrap, writes to `bootstrap_table3_results_11/`) → `analyze_table3_bootstrap.py` (assembles the printed table).
- **Tables 4/5** (generative ablations, incl. MESMER-M/DiffESM baselines): `bootstrap_table45.py` / `bootstrap_diffesm.py` / `bootstrap_mesmer.py` (write to `bootstrap_table45_results/`) → `analyze_table45_bootstrap.py`.
- **Alternative train/test split tables**: `bootstrap_a2_flow.py` (writes to `bootstrap_a2_flow_results/`).

All use the same procedure: 150-draw bootstrap resampling initializations and ensemble members, reported as mean ± 1.96 standard deviations (`analysis/bootstrap_metrics.py` has the shared mechanics).

## Scope

Keep the table-bootstrap result summaries with their generating scripts. Alternative-split, conditioning, and corrected-checkpoint comparisons are retained as evidence for the submission, even when they are not standalone main-text figures. See [the workflow inventory](../docs/paper_workflows.md).

## Metric conventions (October 2026 revision)

SSR for a predicted ensemble of M members verified against the mean of K
independent reference members uses `sqrt(1/M + 1/K) * sqrt(spread_variance / mse)`.
The exchangeable-ensemble population reference is 1. The paper uses M=K=5.
Historical SSR values used `sqrt(1 + 1/M)` and must be divided by sqrt(3),
including their bootstrap uncertainties. Bundled NPZ results now include
`ssr_normalization=ensemble_mean_v1` and ensemble-size metadata. The two table
reporters use `ssr_normalization.load_paper_bootstrap`, which converts unmarked
legacy five-versus-five archives in memory and does not rescale marked files.
External cached metric tensors made with the old code must be regenerated or
explicitly converted before comparison; their normalization cannot be inferred
from the legacy `spskr` key alone. RMSE and other metrics are unchanged.

The historical functions and filenames containing `psd` are retained for
compatibility. The temporal diagnostic actually computes the **absolute,
unnormalized FFT amplitude**, not squared power or power spectral density.
Its labels and manuscript description now say Fourier amplitude and give the
original variable units. It averages valid grid points without latitude
weighting. The horizontal coordinate is period in months, with the shortest
retained period just over two months for the 118-sample sequences. ArchesClimate
and MESMER-M use all eleven starts; DiffESM contributes six complete starts to
the spectrum and climatology because its five later records are shorter.
